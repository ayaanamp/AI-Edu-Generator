# 📚 AI Educational Content Generator

## 📌 Project Overview
The AI Educational Content Generator is an AI-powered educational assistant designed to help students generate quizzes and study materials from educational content such as PDF and TXT files.

The application can:
- Generate quiz questions automatically
- Convert educational content into audio
- Store quiz history
- Support multiple input formats
- Provide a simple learning dashboard

This project was developed as part of the AI Internship Program.

---

# 🚀 Features

- 📄 PDF Upload Support
- 📄 TXT File Upload Support
- 🧠 Automatic Quiz Generation
- 🔊 Text-to-Speech Audio Output
- 💾 Quiz History Storage
- 🌐 Streamlit Web Application
- 📚 Educational Content Processing
